# Setup Instructions for Video Preprocessing Project

## Prerequisites
- Python 3.11 or higher installed
- Git installed

## Clone the Repository
git clone https://github.com/Malaika-Saleem/FYP_self.git
cd "Video Preprocessing"

## Create Virtual Environment (if not already present)
python -m venv venv

## Activate Virtual Environment
# On Windows:
venv\Scripts\activate

# On macOS/Linux:
# source venv/bin/activate

## Install Dependencies
pip install opencv-python flask numpy pillow imagehash werkzeug

## Run the Application
# To run the Flask app:
python app.py

# To run webcam processing:
python webcam_processor.py

# To run video processing:
python video_processing.py

# To run video segmentation:
python video_segmentation.py

# To run video compression:
python video_compression.py

## Deactivate Virtual Environment (when done)
deactivate
